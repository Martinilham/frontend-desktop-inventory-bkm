# Inventory BKM Desktop

## Prasyarat
- Flutter SDK terinstal dan tersedia di PATH.
- Backend sedang berjalan di http://localhost:3000.

## Jalankan backend
1. Buka terminal di folder backend.
2. Jalankan:
   - npm install
   - copy .env.example .env
   - npm start

## Jalankan frontend desktop
1. Buka folder FRONTEND/DESKTOP.
2. Jalankan file run.bat.
3. Jika Flutter belum terinstal, instal dulu Flutter SDK dan pastikan folder bin ada di PATH.
